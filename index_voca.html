단어 가져오기

폴더와 서브폴더를 만들어 단어장에 한꺼번에 등록해요. 이미 있는 단어는 새로 만들지 않고, 폴더가 비어 있으면 그 폴더로만 넣어요.
엑셀: 파일 이름 = 폴더, 시트 탭 이름 = 서브폴더. 열 머리글은 단어 · 뜻 · 예문 · 해석(품사·폴더·서브폴더·난이도·팁도 가능)으로 쓰면 자동 인식해요.

설정

자동: 인터넷이 되면 온라인, 끊기면 오프라인. 오프라인 기록은 연결되면 자동으로 시트에 반영돼요.
⚙️ 고급 · 서버 주소 (보통은 건드리지 않아도 돼요)
100%
누르면 바로 바뀌어요 (70~150%). 이 기기에서만 적용돼요.
💡 크롬에서 너무 크게 보이면: 크롬 ⋮ → 설정 → 접근성에서 글자 크기를 100%로 두고, 앱 안에서는 90% 안팎으로 맞추는 것을 권해요.
설치하면 주소창 없이 전체 화면으로 열리고, 한 번 접속해 두면 인터넷이 없어도 열려요.
🤖 삼성 폰 · 갤럭시 탭
삼성 인터넷
  1. 앱 주소(dtrjeon.github.io/voca/index_voca.html)를 엽니다.
  2. 아래 ≡ 메뉴를 누릅니다.
  3. 현재 페이지 추가 → 홈 화면을 고릅니다.
  4. 이름을 확인하고 추가를 누릅니다.
크롬
  1. 오른쪽 위 ⋮를 누릅니다.
  2. 홈 화면에 추가 또는 앱 설치를 누릅니다.
  3. 설치 / 추가를 누릅니다.
🍎 아이폰 · 아이패드
Safari로 열어야 해요 (다른 앱 안의 브라우저에서는 안 보일 수 있어요)
  1. 앱 주소를 Safari에서 엽니다.
  2. 아이폰은 아래쪽, 아이패드는 위쪽의 공유 버튼(□ 위쪽 화살표)을 누릅니다.
  3. 목록을 올려 홈 화면에 추가를 누릅니다.
  4. 이름을 확인하고 추가를 누릅니다.
설치한 뒤 홈 화면의 아이콘으로 열어야 앱처럼 보여요. 앱 파일을 새로 올린 뒤에는 한 번 완전히 닫았다가 다시 열면 새 버전이 적용돼요.
